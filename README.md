# **ОТЧЕТ О ВЫПОЛНЕНИИ ПРОЕКТА**  
**Наименование проекта:** Разработка программного ядра для детектирования координат лазерного луча  
**Сфера деятельности заказчика:** Образовательные технологии  
**Срок выполнения работ:** 45 дней  

---

## 1. Введение и Цель Проекта
Настоящим отчетом подтверждается успешное выполнение работ по разработке программного ядра на языке **C#** для высокоточного обнаружения и определения координат лазерной точки на проекционной поверхности. Основной целью проекта было создание надежного, точного и расширяемого ядра, реализующего полный функционал калибровки системы и детекции лазера, с предоставлением простого демонстрационного интерфейса на **WinForms** для верификации результатов.

---

## 2. Выполненные Работы и Соответствие Требованиям

В полном объеме реализован весь согласованный функционал, соответствующий пунктам технического задания:

- **Модуль для получения видеопотока** и выбора камеры из списка доступных в системе устройств.
  
- **Алгоритм калибровки проекционной поверхности:**  
  Процесс инициируется и завершается нажатием кнопки "Калибровка". В ходе его работы система в реальном времени анализирует видеопоток, определяет контур экрана по заданным порогам яркости и отображает его зеленым контуром для визуального подтверждения пользователем.
  
- **Функция проверки геометрии экрана:**  
  Алгоритм стремится найти четырехугольник, углы которого максимально приближены к 90 градусам, что минимизирует ошибки перспективы при последующем расчете координат.

- **Интеграция настройки чувствительности через пороги яркости:**  
  Предоставлены регулировки для порогов яркости экрана (рекомендовано: ~100/255 для затемненного помещения) и порогов яркости лазера (рекомендовано: ~200/255 для затемненного помещения), что позволяет гибко адаптировать систему к любым внешним условиям.
  
- **Реализован параметр "Задержка лазера" (в секундах):**  
  Данная функция обеспечивает корректную регистрацию перманентного лазерного луча, исключая ложные срабатывания на кратковременные помехи. Система фиксирует выстрел только если луч стабильно присутствует в течение заданного пользователем времени.

- **Два режима стрельбы:**  
  1. "Режим с пристрелочными выстрелами и задержкой" для точной работы.  
  2. "Режим без ограничений" для непрерывного отслеживания.

## 3. Примененные Архитектурные Подходы

**Современные архитектурные подходы и паттерны проектирования:**

- **Внедрение зависимостей (Dependency Injection) и Слоистая архитектура:**  
  Код четко разделен на независимые модули (UI, бизнес-логика, инфраструктура), что значительно упрощает тестирование, сопровождение и будущую модификацию системы.
  
- **Паттерн "Фасад":**  
  Реализован класс-координатор (`ScreenController`), который предоставляет простой интерфейс для сложной подсистемы обработки изображений, скрывая от основного кода сложность работы с фильтрами, контурами и валидацией.
  
- **Паттерн "Стратегия":**  
  Ключевые алгоритмы (анализ контуров, применение фильтров, валидация) инкапсулированы в отдельные сервисы, работающие через единые интерфейсы. Это позволяет гибко менять и подбирать алгоритмы без переписывания кода всей системы.
  
- **Принцип единственной ответственности (SRP):**  
  Каждый класс системы отвечает за одну конкретную задачу (например, `UdpSender` — только за отправку данных, `AngleComputer` — только за вычисление углов), что делает код более понятным и устойчивым к ошибкам.

Разработанное программное обеспечение полностью готово к использованию. Ядро программы обеспечивает точное и стабильное определение координат лазерной точки после проведения предварительной калибровки. Демонстрационный интерфейс на **WinForms** позволяет проверить работоспособность системы, произвести все необходимые настройки и получить визуальное подтверждение корректности работы алгоритмов.
