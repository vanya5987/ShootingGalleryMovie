# **Ядро системы для лазерного тира на C#**

**Наименование проекта:** Разработка программного ядра для детектирования координат лазерного луча  
**Сфера деятельности заказчика:** Образовательные технологии  
**Срок выполнения работ:** 45 дней  

---

## 🎯 Цель проекта

Основной целью проекта было создание надежного и точного программного ядра для высокоточного обнаружения и определения координат лазерной точки на проекционной поверхности. Ключевыми задачами были:
- Разработка алгоритма калибровки системы.
- Создание функционала для детекции лазерной точки с максимальной точностью.
- Разработка простого демонстрационного интерфейса для верификации результатов на **WinForms**.

---

## 🧰 Выполненные работы и соответствие требованиям

Все согласованные функциональные требования были успешно реализованы, включая:

### 🔄 Модуль получения видеопотока:
- Выбор камеры из списка доступных устройств.
  
### 🔍 Алгоритм калибровки проекционной поверхности:
- Реализация алгоритма, который анализирует видеопоток, определяет контур экрана по порогам яркости и отображает его для визуального подтверждения.

### 📐 Проверка геометрии экрана:
- Алгоритм находит четырехугольник с максимальными углами в 90 градусов, минимизируя ошибки перспективы при расчете координат.

### 🎛 Настройка чувствительности:
- Введение регулировок для яркости экрана и лазера, что позволяет адаптировать систему под различные условия освещенности.

### ⏳ Параметр "Задержка лазера":
- Реализация задержки на регистрацию лазера для исключения ложных срабатываний.

### 🎯 Режимы стрельбы:
- Два режима для точной работы и непрерывного отслеживания лазерного луча.

##№ 📦 Результат
- Демонстрационный интерфейс на **WinForms** предоставляет пользователю возможность настроить параметры и получить визуальное подтверждение точности работы системы.

## 🧩 Архитектура

В проекте применены современные архитектурные подходы, что обеспечило высокое качество кода и легкость в поддержке:

- **Dependency Injection и Слоистая архитектура:**  
  Все модули разделены (UI, бизнес-логика, инфраструктура), что упростило тестирование и сопровождение.
  
- **Паттерн "Фасад":**  
  Класс-координатор (`ScreenController`), который скрывает сложность подсистемы обработки изображений.

- **Паттерн "Стратегия":**  
  Ключевые алгоритмы инкапсулированы в отдельные сервисы, что позволяет гибко менять алгоритмы без переписывания кода.

- **Принцип единой ответственности (SRP):**  
  Каждый класс отвечает за одну задачу (например, `UdpSender` — за отправку данных, `AngleComputer` — за вычисление углов).
